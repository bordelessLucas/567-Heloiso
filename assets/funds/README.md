# Fotos dos FIIs

Pasta com imagens locais por ticker (`TICKER.png`).

- O app carrega via `src/data/fundLogos.ts`.
- Se um ticker **não** tiver arquivo mapeado, a UI usa a **abreviação do nome** como avatar.
- Os PNGs atuais são placeholders de marca (amarelo Mercado FiiS) para o MVP — substitua pelos logos oficiais quando disponíveis.
